Landmark simulation projects, public project pages, and an initial open-repository survey.
This is a selective genealogy rather than an exhaustive list. Dates indicate the project’s landmark release/publication era. “Repository” means public code or project tooling was found; it does not necessarily mean the full production simulation source is open.

GitHub & open-code survey

Initial survey: repositories directly tied to the projects above, plus adjacent open tools worth evaluating for Uranometria. “Official/linked” is stronger than “related”.

Simulation source
Can run/generate cosmological simulations.
Analysis/data tooling
Reads or analyzes a project’s released outputs.
Initial conditions
Creates inputs for zoom or cosmological runs.
Browser/visualization
Potentially useful for a lightweight Uranometria frontend.
Official / simulation sourceabacusorg/abacus-public

High-performance N-body code underlying the Abacus family.

Official / suite + data toolingabacusorg/AbacusSummit

Simulation specifications, cosmology grid, readers and documentation for AbacusSummit.

Official / analysis toolingfranciscovillaescusa/CAMELS

CAMELS library, scripts and analysis infrastructure for the public simulation outputs.

Official / public-data toolingillustristng/illustris_python

Python interface and examples for the Illustris/TNG public data releases; the organization also provides MATLAB, IDL and Julia readers.

Project-linked / simulation sourceMP-Gadget/MP-Gadget

Massively parallel cosmological SPH code used for BlueTides and ASTRID.

Related / alternative DM dataeonadler/COZMIC

Public products for beyond-CDM cosmological zoom simulations; directly relevant to the alternative-cosmology branch.

Related / simulation sourcejmd-dk/concept

Open cosmological N-body code in Python/Cython, with fluids, massive neutrinos and non-standard species support.

Related / initial conditionscosmo-sims/MUSIC2

Multi-scale initial-condition generator for high-resolution cosmological zoom simulations.

Related / differentiable simulationcosmo-sims/DISCO-DJ

JAX-based differentiable cosmological simulation tooling — useful for the ML/emulator genealogy after D³M.

Related / Cosmic Dawn21cmFAST/21cmFAST

Fast semi-numerical 3D simulations of early-Universe density, ionization, temperature and 21-cm fields.

Related / browser visualizationnicosmo/cosmic_web_explorer

WebGPU cosmic-web explorer with ΛCDM, wCDM and dynamic w₀wₐ dark-energy controls. Particularly interesting for a mobile/web Uranometria experiment.

Related interactive atlases

Visualization projects are kept separate from the simulation genealogy. They can nevertheless supply architecture, datasets, rendering techniques, or interoperability ideas for Uranometria.

Open atlas / architecture candidateUniverse Atlas

True-scale WebGPU atlas spanning 10²⁷ to 10⁻¹⁶ m in one continuous scene. It combines measured catalogues with explicitly marked illustrative regions, supports deep time and proper motion, and includes the Local Universe, Sgr A* / S-stars, Solar System, probes, small bodies and exoplanets.

Our fork: mardukasoka/universeUpstream
Open atlas / Solar System scaleAtlas of Space — Leleākūhonua

Useful reference for the outer-Solar-System / roughly light-day-scale visualization branch, including extreme trans-Neptunian objects.

Our fork: mardukasoka/atlasof.space
